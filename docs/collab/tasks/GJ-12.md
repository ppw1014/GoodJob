## 背景（为什么做）

三项都来自 GJ-03 / GJ-05 / GJ-11 的验收观察，均已挂 backlog 等 Owner 裁决，2026-08-02 Owner 一次性裁定全做。

### 一、全部项目被排除时扫描终态为 `failed`

`_final_status` 中 `available == 0` 即返回 `failed`。若 Owner 用 `[[goodjob.excluded_projects]]` 排除了工作区内全部项目，这是一次**完全按配置执行成功**的扫描，却被标成故障。

后果不是"名字难看"。实测 `history.py:244`：

```sql
AND sr.status IN ('completed', 'partial')
```

`failed` 的运行会被下游**整个过滤掉**。Owner 的配置意图被当成了故障处理。

### 二、`ignore_pattern_unsupported` 的原始模式行不是独立字段

覆盖摘要里 `ignore_pattern_issues` 的原始模式行埋在英文句子 `Ignore pattern '<raw>' uses syntax with non-Git semantics.` 中。GJ-05 契约 3 要求"字段必须说明来源、原始模式行与近似语义"，合起来确实说清了，但任何要按模式分组或过滤的呈现都得反解析字符串。

### 三、`check-doc-links.py` 的最低 Python 版本是隐含的

Architect 实测该脚本在 Python 3.9.6 / 3.12.13 / 3.14.3 上结果完全一致（均 `39 files`、测试 `OK`），只用到 walrus 等 3.8+ 特性。**Owner 已裁定不固定解释器**——三版本无差异，且加运行期版本守卫防不住语法错误（`SyntaxError` 在解析期就发生，守卫代码没机会执行）。

但"只能用 3.9+ 语法"这个约束目前谁都看不见。

## 目标（做成什么样）

Owner 主动排除全部项目不再被下游当成故障；ignore 近似告警的原始模式行可被机器直接取用；文档检查器的语言版本约束对下一个编辑者可见。

## 接口契约

Architect 给定，不得擅改。三项**各自独立**，实施顺序自选。

### 契约 1-3：扫描终态

1. `_final_status` 的 `available == 0` 分支改为：**仅当 `dispositions["excluded"] == 0` 时才返回 `failed`**；否则继续走其后的既有判定链（`carried_forward` / `failed_no_baseline` → `partial`；有非 `info` issue → `partial`；否则 `completed`）。
2. **不新增 status 取值，不做 schema migration。**现有枚举 `running / completed / partial / failed / interrupted` 够用。
3. **其余判定逻辑一行不改。**本项只改 `available == 0` 那一个条件，不重构该函数，不调整其后各分支的顺序或阈值。

### 契约 4-5：ignore 原始模式行

4. `ignore_pattern_unsupported` 类 `ScanIssue` 进入覆盖摘要时，**原始模式行成为独立字段**（例如 `raw_pattern`），与来源文件、近似语义说明并列。
5. **不改 `ScanIssue` 的既有字段语义，不改 message/remediation 的文案内容。**原始模式行仍可继续出现在 message 里（人读友好），本项只要求它**同时**作为独立字段可取。若为此需要在 issue 上新增承载字段，允许；但不得改动其他 issue 类型的形状。

### 契约 6：版本约束显式化

6. `scripts/check-doc-links.py` 的模块 docstring 增加一行，写明"仅使用 Python 3.9+ 语法"及其理由（门禁经 `python3` 调用，该名字在不同机器上解析到的版本不同）。**只加这一行，不加运行期版本检查**——`SyntaxError` 发生在解析期，运行期守卫拦不住，加了是假防护。

## 实现指引

- 契约 1 的改动应当是**一个条件表达式**的修改。若你发现需要动更多，说明我对该函数的理解有误，按 L1 停工。
- 契约 1 的测试要区分两种零合资格：**全部被排除**（应 `completed` 或按既有链走 `partial`）与**全部失败无基线**（应仍为 `failed`）。两条都要有，否则等于没测。
- 契约 4 的字段名自选，写进交付报告；判据是"不用解析字符串就能取到原始模式行"。
- 三项互不依赖，可以分三个 commit，也可以一个。**分开更好**——万一某项要打回，另两项不受牵连。
